# demo-data

실제 백엔드가 돌려준 응답을 그대로 받아 둔 것입니다. 두 곳에서 씁니다.

- `tests/mock-api.ts` — Playwright가 백엔드 없이 돌도록 라우트를 가로채 이 파일들을 돌려줍니다.
- `app/api/demo/[...path]/route.ts` — `NEXT_PUBLIC_DEMO=1`로 배포했을 때 앱이 읽는 API입니다.

시세·지표·해석 문장은 손으로 고치지 마세요. 값이 진짜라서 의미가 있습니다 — 긴 한글 문장이
살아 있어야 가로 넘침 회귀를 잡을 수 있고, 데모 화면도 실제로 계산된 숫자를 보여줍니다.

**예외: `portfolio.json`과 `watchlist.json`은 손으로 쓴 예시입니다.** 이 둘은 "누가 무엇을
들고 있는가"라서, 캡처본을 그대로 두면 공개 배포와 저장소에 개인의 보유·관심 종목이 남습니다.
지금 값은 아무의 계좌도 아니며 합계·비중·손익만 서로 맞게 맞춰 놓은 것입니다. 다시 캡처하게
되더라도 이 두 파일은 예시로 덮어쓰세요.

다시 캡처하려면 백엔드를 띄우고 해당 엔드포인트의 응답을 그대로 저장하면 됩니다.
Prettier 대상에서 제외돼 있으므로 포맷은 바뀌지 않습니다.
